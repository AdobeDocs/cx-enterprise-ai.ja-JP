# キャンペーンを停止 {#stop-campaign}

ユーザーは、キャンペーンの詳細ページから直接アクティブに送信しているキャンペーン（ライブ キャンペーン）を停止できるようになりました。 キャンペーンを停止することは永続的です。受信者は、キャンペーンの進行をすぐに停止し、キャンペーンを再開したり、後で再開したりすることはできません。

## 前提条件

- キャンペーンはライブ（アクティブに送信）状態である必要があります。 「停止」アクションは、ドラフト、スケジュール済み、または既に停止しているキャンペーンには使用できません。

## この機能の機能

キャンペーンの詳細ヘッダーに「キャンペーンを停止」アクションが表示されるのは、キャンペーンがライブになるときです。 これを選択すると、アクションが永続的であることを示す確認ダイアログが開きます。 確認すると、バックエンドが呼び出されてキャンペーンが停止します。成功すると、キャンペーンのステータスが「停止」に変わり、確認メッセージが表示されます。

### 主な行動

- キャンペーンの停止アクションは、キャンペーンがライブ中（アクティブに送信している場合）にのみ表示されます。
- 停止は永続的です。受信者はキャンペーンを進めなくなるため、再開できません。
- 確認ダイアログでは、キャンペーンを停止する前に、ユーザーが明示的に確認する必要があります。
- 停止後、キャンペーンのステータスバッジが「停止」に更新されます。
- 停止リクエストが失敗した場合は、エラーメッセージが表示され、キャンペーンは有効なままになります。

## 活用方法

1. 現在公開中（アクティブに送信している）のキャンペーンを開きます。
2. キャンペーンの詳細ヘッダーで、**キャンペーンの停止**&#x200B;をクリックします。
3. 確認ダイアログで、「キャンペーンの停止は永続的です」という警告を確認します。 すべての受信者が進行を停止し、キャンペーンを再開できません。」
4. 「**停止**」をクリックして確認します。
5. “キャンペーンが停止しました”。 確認メッセージが表示され、キャンペーンのステータスが「停止」に更新されます。

### 入力フィールド/パラメーター

該当なし – この機能は、入力フィールドのない単一の確認アクションです。

## UI コールアウト

> **テクニカルライター注**：次のスクリーンショットが必要です：

- [ ] ライブキャンペーンに表示される、キャンペーン詳細ヘッダーの「キャンペーンを停止」ボタン
- [ ]永続性に関する警告が表示された確認ダイアログ
- [ ]停止が成功した後の「停止しました」ステータス バッジ
- [ ]停止が失敗した場合に表示されるエラーメッセージ

## この機能で実行できない処理

- キャンペーンを一時的に一時停止することはありません。 停止したキャンペーンを再開する方法はありません。停止は一方向のアクションです。
- 同じキャンペーンレコードから停止したキャンペーンを再開または再開することはできません。
