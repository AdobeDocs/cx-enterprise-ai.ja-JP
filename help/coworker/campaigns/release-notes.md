# Adobe CX Enterprise Coworker Campaigns リリースノート {#release-notes}

Adobe CX Enterprise Coworker Campaignsのリリースは、継続的な配信モデルにもとづいて動作するため、機能のデプロイメントに対するよりスケーラブルで段階的なアプローチが可能になります。

## 2026年7月 {#july-2026}

**リリース日：2026年7月23日**

* キャンペーンの送信を、選択した時間に一度、または定期的にスケジュールできます
* 連絡先リストから購読解除リストを管理し、キャンペーンメール設定で購読解除パラメーターを設定します
* 新しいフォームのインベントリとエディターでフォームを作成および管理する
* 既存の接続を更新する場合など、資格情報が失敗した場合に、コネクタの設定でより明確なガイダンスが表示される
* Marketo接続でExperience Cloud URLがサポートされるようになりました
* ドメインと送信者ウィザードは、ドメインが公開される前に、DNS レコードの問題をさらに検出します
* キャンペーン入力の追加メニューから直接コネクタを追加する
* 在庫ページには、まだ表示するものがない場合、わかりやすい図で空の状態が表示されます
* キャンペーンのインサイトは、各指標を強化するデータソースを示します

* キャンペーンにコミットする前に、サンプルオーディエンスをプレビューします
