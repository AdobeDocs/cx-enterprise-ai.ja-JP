# キャンペーンのスケジュール {#schedule-campaign}

キャンペーンを開始する際に、ユーザーは、すぐに、特定の将来の日時に、または繰り返し（繰り返し）スケジュールに基づいて、正確に送信を選択できるようになりました。 また、利用者が後から来て、既に開始されているキャンペーンやスケジュールされているキャンペーンのスケジュールを変更することもできます。

> **変更**：以前は、キャンペーンは直ちに開始することしかできませんでした。 このリリースでは、1回限りの今後のスケジュール設定、定期的なスケジュール、および起動後にスケジュールを編集する機能が追加されます。

## 前提条件

- キャンペーンを開始する準備ができている必要があります（すべての必要な設定が完了しました）。
- キャンペーンを起動可能な状態にする以外に前提条件は必要ありません。

## この機能の機能

オーディエンスが施策を開始すると、3つのスケジュールモードのいずれかを選択し、次に「確認」します。 選択したスケジュールは、キャンペーンがいつ送信を開始し、繰り返しキャンペーンの場合は、繰り返し頻度と送信が終了するか（または終了するか）を決定します。 キャンペーンをスケジュールまたはライブにすると、そのスケジュールはキャンペーン設定から編集できます。

### 主な行動

- 起動時には、3つのスケジュールモードを使用できます：**今**、**スケジュールが1回**、**繰り返し**。
- 今後スケジュールされたキャンペーンでは、開始時間が到着するまで「スケジュール済み」ステータスが表示され、その後、自動的に「ライブ」に切り替わります。
- 開始した定期的なキャンペーンには、その繰り返しの概要と共に「ライブ」が表示されます（例：「毎週火曜日、木、午前9:00」）。
- 繰り返しキャンペーンは、無期限（「なし」終了）または特定の終了日まで実行するように設定できます。 1回限りのキャンペーンと即時キャンペーンは、1回実行するため、終了日オプションがありません。
- ユーザーは、キャンペーンの設定から、同じスケジュールオプションを使用して、既に開始またはスケジュール済みのキャンペーンのスケジュールを編集できます。

## 活用方法

**起動時にキャンペーンをスケジュールするには：**

1. キャンペーンから、**起動する準備ができました**&#x200B;をクリックします。
2. 起動ダイアログで、スケジュール オプションを選択します。
   - **今** — キャンペーンの送信はローンチ直後から開始されます。
   - **1回のスケジュール** – 今後のスケジュール **開始日** （日時を一緒に）を選択します。
   - **繰り返し** — **頻度** （日単位、週単位、月単位）と開始時間を選択し、繰り返しパターンを設定します（以下のフィールドを参照）。
3. 「繰り返し」を選択した場合は、キャンペーンの終了日を&#x200B;**なし**&#x200B;か&#x200B;**日**&#x200B;のどちらかを選択し、該当する場合は終了日を選択します。
4. 選択したスケジュールでキャンペーンを開始することを確認します。

**既存のスケジュールを編集するには：**

1. キャンペーンを開き、設定に移動します。
2. 「スケジュール」セクションを検索し、現在のスケジュールの概要を選択します。
3. 上記と同じオプションを使用してスケジュールを更新します。
4. 変更を保存します。

### 入力フィールド/パラメーター

| フィールド | 説明 | 必須？ |
| --- | --- | --- |
| スケジュールモード | 「今すぐ」、「スケジュールを1回」または「繰り返し」の選択 | ○ |
| 開始日 | キャンペーンが開始される日時（1回のスケジュール モード） | はい、スケジュールは1回です |
| 頻度 | 日単位、週単位、月単位（定期モード） | はい、繰り返し |
| 開始時間 | 定期的なキャンペーンが送信される時間帯 | はい、繰り返し |
| 曜日 | キャンペーンが繰り返される日 | はい、週単位で |
| ある月の日付 | キャンペーンが繰り返される月の曜日 | はい、月間頻度で |
| キャンペーンを終了 | なし、または特定の終了日 | はい、繰り返し |

## UI コールアウト

> **テクニカルライター注**：次のスクリーンショットが必要です：

- [ ]開始ダイアログに「今すぐ/スケジュールに1回/繰り返し」オプションが表示される
- [ ] スケジュールは日時ピッカーに1回のみ適用されます
- [ ]繰り返しオプション：頻度ピッカー、週単位の日単位トグル、月単位の日単位グリッド
- [ ] 「キャンペーンの終了」は日付選択で使用できません
- [ ] キャンペーンの「スケジュール済み」ステータス バッジは、開始時刻を待っています
- [ ]繰り返し概要が記載された「ライブ」ステータスのバッジ（例：「毎週火曜日、木、午前9時））
- [ ] キャンペーン設定の「スケジュール」セクション。編集エントリポイントが表示されます

## この機能で実行できない処理

- 「2週間ごと」や「3日ごと」などのカスタムの繰り返し間隔はサポートされていません。標準のデイリー、ウィークリー、またはマンスリーの頻度のみが使用できます。
- 「月の第2月曜日」など、相対的な月間繰り返しはサポートされていません。月間特定の曜日の選択のみが利用可能です。
- **Now**&#x200B;または&#x200B;**スケジュールが**&#x200B;のキャンペーンの終了日は提供されていません。終了日は、定義によって1回実行されるキャンペーンであるため、「繰り返し」を選択した場合にのみ使用できます。
